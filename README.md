# Little Lemon — Mobile UI

Three iPhone-sized screens (390 × 844, light mode) for the Little Lemon Mediterranean restaurant app:

1. **Onboarding** — logo, "Let's get to know you", First name + Email inputs, disabled Next button
2. **Home** — slim header, green hero with search, category pills, menu list
3. **Profile** — avatar, personal info, email notifications, Log out, Discard / Save

Palette: green `#495E57`, yellow `#F4CE14`, grey `#EDEFEE`, text `#333333`, salmon `#EE9972`.
Type: Markazi Text (headings), Karla (body). Flat, no gradients.

Open `index.html` in a browser. All artwork is inline SVG; only the Google Fonts stylesheet is external.
